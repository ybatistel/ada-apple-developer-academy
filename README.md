## AvantBarber

Sistema de agendamentos para barbearias, criado pra resolver um problema real: uma
barbearia com alto fluxo de clientes gerenciando tudo manualmente pelo WhatsApp, o que
causava conflitos de horário e falhas de comunicação entre barbeiros.

A solução é uma aplicação + automação com n8n + landing page. Por ser meu primeiro
projeto desse porte e feito pra um cliente real, aproveitei pra aprender ao máximo:
levantamento de requisitos, modelagem do banco de dados e organização com Kanban,
desde o papel até o código.

O maior aprendizado é que desenvolvimento é, na essência, resolver problemas reais de
pessoas e negócios.
